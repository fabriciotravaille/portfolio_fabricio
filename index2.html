Meus próximos passos:

Atualmente, meu foco principal é consolidar minha base no desenvolvimento web, indo além da estruturação visual com HTML e CSS para dominar a lógica de programação com JavaScript. Depois de construir projetos práticos como a calculadora e páginas estruturadas de conteúdo, meu próximo passo é entender como tornar as aplicações cada vez mais interativas, dinâmicas e preparadas para resolver problemas reais, sempre praticando a organização do código e a responsividade para diferentes telas.

Como estudante na área de tecnologia, acredito que aprender na prática é o melhor caminho para evoluir. Nos próximos meses, quero aprofundar meus conhecimentos em ferramentas de versionamento como o Git e o GitHub, além de começar a explorar bancos de dados e frameworks modernos. Meu objetivo é continuar me desafiando com novos projetos acadêmicos e pessoais, transformando cada erro e cada linha de código em experiência para construir soluções cada vez mais completas.
